## Arithmetic
Arithmetic operators like *, +, or - can be part of an expression like 3 * 2 or tomatoes + potatoes.

#### Updating Variables
You can reassign variables, as long as they keep their type:
```
int tomatoes{80};
tomatoes = tomatoes - 5;      // tomatoes is now 75 
int potatoes = (32 * 2) + 11; // potatoes is now 75 as well
```
## Formatting 
Whitespace is used for formatting source code and includes spaces, tabs, or newlines. As the compiler ignores unnecessary whitespace, you can use it to structure your code. Smart use of whitespace can improve the readability of your code. There are different formatting standards, but these are all conventional and not enforced by the compiler.
```
// Formatting makes it easier to find bugs

int egg_yolks =  3;
int      yeast = 15;

int flour=500;int sugar=200; // compact, but difficult to read
```
